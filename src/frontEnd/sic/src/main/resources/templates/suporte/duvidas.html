Entenda quais Imagens o Sistema Aceita

Para garantir uma análise eficiente, é importante saber quais tipos de imagens podem ser utilizadas no sistema. Abaixo, você verá os dois formatos aceitos e suas características.

Imagem com Zoom

Capturada diretamente do microscópio, essa imagem possui alta nitidez e aproximação. Esse formato permite ao sistema extrair detalhes com mais precisão, aumentando a eficiência da análise.

Imagem sem Zoom

Capturada com uma câmera comum, essa imagem possui um campo de visão mais amplo. Embora seja aceita pelo sistema, a qualidade pode ser inferior, impactando na identificação dos elementos.

Recomendação: Ambos os formatos são aceitos, mas para uma melhor performance e precisão, recomenda-se o uso de imagens com zoom direto do microscópio.
